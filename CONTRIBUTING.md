# Contributing

Thanks for your interest in contributing to the Archyl Developer skill!

## Where to Make Changes

All skill content lives under `plugins/archyl-developer/skills/archyl-developer/`:

- `SKILL.md` — Main skill definition (triggers, tool categories, workflows)
- `references/` — Domain-specific reference files with detailed guidance

## Branching

The default branch is `main`. Please branch from `main` and open PRs against `main`.

## Making a PR

1. Fork or clone this repository
2. Create a feature branch from `main`
3. Make your changes
4. Open a PR targeting `main`

## What to Contribute

- Fix incorrect tool names, parameters, or descriptions
- Add coverage for new Archyl features
- Improve workflow examples
- Add new reference files for missing domains
- Fix typos and improve clarity

## Guidelines

- Keep the SKILL.md focused and scannable — detailed content goes in `references/`
- Tool names must match exactly what Archyl's MCP server exposes
- Include practical examples in reference files
- Test your changes against a running Archyl instance if possible

## Questions?

Open an issue on this repository.
